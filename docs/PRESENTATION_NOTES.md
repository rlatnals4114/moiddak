# 모이딱 발표 5장 · 내용 정리와 시연 순서

> 발표자료 제작용 원고 재료다. **구현·확인된 기능만** 적었다. 사용자 테스트 수치는 `USER_TEST_SHEET.md` 에 실제로 기록한 값만 넣는다(아래 `[ ]` 칸).
> 경쟁 서비스의 최신 기능·가격은 이 문서에서 조사하지 않았다. "최초/유일" 같은 표현은 쓰지 않는다.

## 1장. 문제와 서비스 소개

- 한 문장: **"모이딱은 소규모 모임 주최자가 누가 아직 응답하지 않았는지 확인하고, 일정과 장소를 같은 링크에서 확정하도록 돕는 모바일 웹입니다."**
- 대상: 카카오톡으로 3~8명 모임(친구 약속, 독서모임, 동아리)을 잡는 주최자.
- 화면: 모임방 홈(지금 할 일 카드 + 참가자 캐릭터 응답 상태).

## 2장. 문제 정의와 공감

- 직접 경험(기획 단계 인터뷰에서 확인한 사실):
  - When2meet 류 도구는 가능한 인원은 보이지만 **누가 아직 안 했는지**는 알기 어려웠다.
  - 그래서 단톡방에 "안 한 사람들 투표해 주세요"를 다시 올렸다.
  - 휴대폰에서 시간표 드래그 입력이 번거로웠다.
  - 장소는 후보·지도 링크·휴무를 여러 대화로 확인해야 했다.
- 핵심 메시지: **"가능한 인원"과 "미응답자"는 다르다.**
- (사실과 가설 구분) 결정 시간이 줄어든다는 것은 아직 가설 → 4장에서 테스트 결과로 이야기.

## 3장. 라이브 시연 (아래 '시연 순서' 참고)

- 보여 줄 기능(모두 배포 주소에서 동작 확인됨):
  1. 모임 만들 때 **일정 정하는 방법 선택**: 간단하게 고르기(A) / 시간표에서 맞추기(B)
  2. 달력 + 후보 카드("3명 가능 / 4명 응답 · 전체 5명")
  3. B 모드 **30분 시간표 히트맵**, 칸을 누르면 가능 / 응답했지만 불가 / 미응답 분리, **교집합 기준 추천 시간**
  4. **미응답자 이름 + 요청 문구 복사**
  5. **카카오맵 실제 검색 → 후보 → 지도 마커**, 선호 투표
  6. 주최자 확정 → **약속 완성 카드 + 공유 문구**

## 5장. 배운 점과 다음 계획

- 배운 점(예시 방향, 실제 경험으로 교체): 기능을 더하는 것보다 "지금 누가 남았고 다음에 뭘 할지"를 보이는 게 핵심.
- 검증된 것: 자동화 테스트(실제 DB, 여러 세션)로 응답·미응답 구분, 본인 응답만 수정, 확정 후 잠금, 지도 후보 저장 등 확인.
- 아직 검증 안 된 것: 실제 결정 시간 단축 효과, 다양한 기기·브라우저에서의 연결 유지.
- 다음 계획: 도트 캐릭터 꾸미기(Figma 시안), 재조율, 장소 먼저 정하기, 캘린더 저장(.ics), 실시간 갱신.

## 시연 순서 (2~3분)

**사전 준비(시연 전)**
- 노트북(주최자) 크롬 + 휴대폰 1대(참가자). 둘 다 배포 주소.
- 시연용 B 모임: 참가자 5명 중 3명은 미리 응답(1명은 "가능한 시간 없음"), **2명 미응답** 상태로 준비. 장소 후보 2~3곳 미리 등록.
- 휴대폰은 미응답자 한 명의 개인 링크로 **미리 연결**해 둔다(시연 중 초대 링크·관리자 링크 화면을 띄우지 않는다).
- 라이브 실패 대비 화면 녹화/스크린샷을 준비하되, 녹화를 라이브라고 소개하지 않는다.

| 순서 | 화면 | 말할 것 | 시간 |
| --- | --- | --- | --- |
| 1 | 노트북 · 모임방 홈 | "지금 3/5명 응답, 캐릭터 빈자리 2개가 아직 안 한 사람" | 20초 |
| 2 | 일정 탭 · 미응답 문구 복사 | "누구에게 다시 물어볼지 바로 복사" (자동 발송 아님) | 15초 |
| 3 | 휴대폰 · 내 시간 입력 | `+ 저녁` 한 번에 선택 → 제출 | 25초 |
| 4 | 노트북 · ↻ 새로고침 → 결과 | 4/5 로 바뀜, 히트맵 진해짐, 칸 눌러 이름 보기, 추천 시간 | 30초 |
| 5 | 노트북 · 일정 확정 | 추천 구간으로 확정 | 10초 |
| 6 | 휴대폰 · 장소 탭 | 지도 검색 → 후보 추가 → 마커 / 선호 투표 | 30초 |
| 7 | 노트북 · 장소 최종 확정 → 홈 | 약속 완성 카드 + 안내 문구 복사 | 20초 |

**시연 중 주의**
- 개인 초대 링크·관리자 복구 링크가 보이는 관리 탭을 화면에 오래 띄우지 않는다.
- 다른 사람 응답은 자동으로 바뀌지 않는다 → `↻ 새로고침` 을 누르며 설명.
- 확정·삭제는 확인 창이 뜬다(일반 브라우저). 시연 리허설을 한 번 할 것.
