## 2. 링크 2종 UI — 변경 전후
| 화면 | 전 | 후 |
| --- | --- | --- |
| 모임방 상세 → 친구 초대하기 | ‘내 초대 링크’(공유하기·복사·새 링크·끄기 한꺼번에) | **‘모임방 초대 링크’**: 카카오톡으로 공유 / 초대 링크 복사 / 다른 앱으로 공유(지원 기기). ‘링크 다시 만들기·끄기’는 작은 접기 안 |
| 모임방 설정 | 멤버 줄마다 개인 링크 버튼, 링크 관리·모임방 주소가 각각 섹션 | 위: 모임방 초대 링크 → 멤버(역할·빼기만) → **‘고급 링크·복구’ 접기**: 이름별 개인 링크·이름 미리 넣기·모든 초대 링크/정원(관리자), 모임방 주소(초대 아님) |
| 약속 관리(링크형) | 참여 링크 + 새 링크/끄기 + 참여한 사람 + 주최자 복구 | **‘약속 초대 링크’**(공유 3버튼) → 진행 안내 3줄 → ‘고급 링크·복구’(다시 만들기·끄기, 다른 기기로 옮기기, 약속 주소, 주최자 복구) |
| 약속 관리(명단형) | 개인 링크 목록 + 약속 링크 + 복구 | **‘약속 초대 링크(사람별)’**: 미연결 사람마다 카카오톡 공유·복사(링크가 이 기기에 있을 때) 또는 ‘초대 링크 만들기’ → 고급 접기 |
| 약속 관리(모임방 약속) | 개인 링크 목록 | ‘약속 초대’: 고른 모임방 멤버만, 새 친구는 **모임방 초대 링크**로 먼저(바로가기) + 미연결 멤버 개인 링크 |
- 문구: 친구 초대하기 / 초대 링크 복사 / 카카오톡으로 공유. ‘토큰·RPC’ 같은 말 없음. 복사 후 “링크를 복사했어요”, 공유 창을 닫아도 오류 없음.
- 권한: 화면만 옮겼고 서버 검사(RPC/RLS) 그대로. 이미 발행된 링크 폐기 없음.

## 3. 카카오톡 공유 카드 · 대체 · OG
- 구현: `public/lib/kakaoShare.js`(SDK 2.8.4, **SRI 해시 고정**, `Kakao.init` 후 `Kakao.Share.sendDefault` 피드), `public/ui/InviteShare.js`(버튼 묶음).
- 카드: 모임방 “○○에 초대해요” + ‘모임방 참여하기’ / 약속 “○○, 날짜를 함께 정해요”(확정 뒤 “○○에 함께해요”) + ‘약속 참여하기’. 공통 이미지, 고정 안내 한 줄, 초대 주소만 — **참가자 이름·일정·미응답자·관리자 링크 없음**(단위 테스트로 확인).
- 대체 순서: 카카오 공유 실패(키 없음·SDK 로드 실패·도메인 미등록·PC 등) → Web Share(지원 시) → 복사 → (복사도 막히면) 직접 복사 창.
- 링크 미리보기(OG): `index.html` 에 공통 메타(제목·설명·1200×630 이미지 `assets/og/moiddak-og.png` — 기존 로고·도트 캐릭터로 제작, 원본 화면 `design/og/og-template.html`). **모든 주소가 같은 미리보기**(해시 라우트라 약속별 정보 없음 → 토큰·이름 노출도 없음).
- 약속별 동적 미리보기(설계만): 해시 대신 서버가 받는 경로(예: `/s/m/<공개 ID>`)를 Worker 가 받아 제목만 넣은 OG HTML 을 돌려주고 `#/…` 로 이동. 단 약속 제목도 비공개 정책(012)이라 ‘공개 동의한 제목’ 칸이 필요 → DB·정책 결정 필요. 이번엔 만들지 않음.
- **사용자가 할 설정(카카오 개발자 콘솔)**: ① [제품 링크 관리] > [웹 도메인]에 `https://moiddak.hackathon-kit.workers.dev` 등록(이미 했는지 확인) ② 개발용 주소에서도 시험하려면 JavaScript SDK 도메인·웹 도메인에 `https://moiddak-dev.hackathon-kit.workers.dev` 추가.

## 4. `.ics` 캘린더
- 구현: `public/lib/ics.js`(순수 함수), `public/ui/AddToCalendar.js`. 확정 일시 상자 안에 **캘린더에 추가하기**(+ 구글 캘린더 대안). 미확정 약속엔 버튼 없음.
- 형식: VCALENDAR/VEVENT, CRLF, 75바이트 줄 접기(한글 안전), 이스케이프, `UID: moiddak-<약속ID>@…`(고정), `DTSTAMP` 생성 시각, `DTSTART/DTEND` 는 저장된 확정 시각을 UTC(Z)로, `SEQUENCE` = 확정 회차−1, `LOCATION` 은 집결지(없으면 첫 방문지) 있을 때만, `DESCRIPTION` 은 장소 목록 + 토큰 없는 약속 주소. 파일 이름 `moiddak-<약속ID>.ics`.
- **끝 시각 없는 약속**: 임의 길이를 넣지 않음 → ‘끝나는 시간’을 골라야 버튼이 켜짐(30분~6시간 중 선택).
- 안내: “캘린더에 저장한 일정은 모이딱에서 바뀌어도 자동으로 바뀌지 않아요”, 카카오톡 안 브라우저면 ‘다른 브라우저로 열기’ 또는 구글 캘린더 안내.

## 6. 기기에서 확인할 항목
1. 모임방 설정 → **카카오톡으로 공유** → 카드(제목·이미지·‘모임방 참여하기’) → 받은 폰에서 버튼 → 참여 화면이 열리는지(**해시 주소 유지 여부**).
2. 약속 관리 → 약속 초대 링크 카카오톡 공유 → ‘약속 참여하기’ → 이름 → 참여.
3. 공유 창 닫기 → 다시 공유 / ‘초대 링크 복사’ 붙여 넣기.
4. 확정 약속 → 캘린더에 추가하기 → iPhone(사파리)·안드로이드(크롬) 캘린더에 제목·날짜·시각·장소가 맞는지. 카카오톡 안 브라우저에서도 시도.
5. 카카오톡·문자에 주소만 붙였을 때 링크 미리보기 이미지가 보이는지(배포 후, 캐시 때문에 늦게 바뀔 수 있음).

## 7. 남은 이슈·리스크
- **카카오 콘솔 ‘제품 링크 관리 > 웹 도메인’ 등록 여부를 확인해야 함**(미등록이면 카드는 가도 링크가 안 열림/4002).
- 해시 주소가 카카오 메시지 버튼에서 유지되는지 미확인 — 안 되면 `/?go=` 같은 서버 경로 입구가 필요(토큰이 서버 요청에 실리게 되므로 별도 설계·결정).
- 링크 원문은 만든 기기에만 있음(그대로) — 다른 기기에서는 ‘다시 만들기’.
- SDK 는 카카오 CDN 에서 불러옴(SRI 고정). 카카오가 같은 버전 파일을 바꾸면 로드가 막혀 자동으로 복사 대체.
- DB 변경 필요 없음.
