# 모이딱 실기기 테스트 시나리오

> 대상 주소: https://moiddak.hackathon-kit.workers.dev
> 이 문서는 **사람이 직접** 휴대폰·노트북으로 진행하는 절차다. Claude 는 실기기 테스트를 하지 않았다. 결과 칸은 직접 채운다.

## 0. 먼저 알아 둘 연결 규칙 (가장 많이 헷갈리는 부분)

모이딱은 회원가입이 없다. 대신 **브라우저마다 자동으로 익명 계정**이 하나 생기고, 개인 초대 링크를 처음 연 브라우저가 그 이름과 연결된다.

| 상황 | 결과 |
| --- | --- |
| 카카오톡에서 개인 링크를 눌러 **카카오톡 안 브라우저**로 열었다 | 카카오톡 안 브라우저가 그 이름과 연결됨 |
| 나중에 같은 링크를 **사파리/크롬**에서 다시 열었다 | 사파리는 **다른 익명 계정**이라 "이미 사용된 초대 링크예요"가 뜸 |
| 단체방의 **모임 링크**만 열었다 | 내용이 안 보이고 "개인 초대 링크로 들어와 주세요" 안내 |
| 연결된 브라우저에서 모임 링크를 다시 열었다 | 정상으로 내 응답 화면이 보임 |
| 브라우저 방문 기록·사이트 데이터를 지웠다 / 시크릿 창 | 연결이 사라짐 → 주최자에게 새 링크 요청 |
| 주최자가 "새 링크 발급"을 눌렀다 | 이전 링크와 이전 기기 연결이 끊기고, 새 링크를 연 브라우저가 연결됨(이미 낸 응답은 남음) |

> 카카오톡 안 브라우저는 앱 안에서 계속 같은 저장소를 쓰는 것이 일반적이지만, **기기·카카오톡 버전마다 다를 수 있어 직접 확인이 필요하다**(아래 T2·T9).

## 1. 준비물

- 주최자: 노트북(크롬 권장) 1대
- 참가자: 휴대폰 2~3대(가능하면 아이폰 1 + 안드로이드 1), 각 휴대폰에 카카오톡
- 테스트용 모임 이름에는 `[테스트]` 를 붙인다.

## 3. 알려진 제약 (테스트 중 '버그'로 오해하지 않기)
- 명단·시간 후보·일정 방식은 만든 뒤 바꿀 수 없다.
- (1.x 약속) 장소 투표는 일정 확정 후에 열렸다. **2.0 부터는 일정 확정 전에도 장소 후보·투표가 가능**하고, 장소 없이 확정할 수도 있다.
- 같은 분류에서 첫 투표가 들어오면 그 분류의 후보 추가·삭제가 잠긴다.
- 실시간 자동 갱신이 아니다. 다른 사람 응답은 `↻ 새로고침` 이나 앱으로 돌아올 때 반영된다.
- 개인 초대 링크 원문은 모임을 만든 브라우저에만 저장된다(다른 기기에서는 `새 링크 발급`).
- 익명 로그인은 같은 인터넷 주소(와이파이)에서 시간당 한도가 있다(Supabase 설정).
