## 1. 조사: 개념 ↔ 실제 모델

| 지시서 개념 | 실제 모델(필드·함수) | 비고 |
| --- | --- | --- |
| 일회성 약속 / 모임방 약속 | `meetings.group_id` null / 값 있음 | 같은 표 |
| 초대 대상 | 그 약속의 `participants` 행 | 모임방 멤버 수와 별개(약속 만들 때 고른 멤버만) |
| 링크 연결 완료 | `participants.user_id` 가 있음 | 개인 초대 토큰 수락(`accept_invite`) 또는 모임방 멤버 연결 시 자동(트리거). 페이지 방문·미리보기만으로는 안 생김 |
| 일정 미응답 | `schedule_submissions` 행 없음 | |
| 가능한 시간 제출 | 제출 행 + `availability_choices`(A)·`grid_availability`(B) 1개 이상 | |
| 가능 시간 없음 제출 | 제출 행 있음 + 선택 0개 | **명시적 제출 행으로 구분됨 → 빈 배열 추정 없음** |
| 참석 의사 확인 | **없음** | 화면에 ‘참석 여부 미확인’으로만 표기 |
| 장소 상태 | 방문지 `itinerary_stops`(또는 예전 `final_places`) / 생략 `meetings.place_skipped`(명시 저장) / 후보 `place_candidates` | 4상태 모두 기존 필드로 구분 가능 |
| 확정 시점 기록 | 확정 후 `submit_schedule` 이 거부됨(상태 `schedule_open` 아닐 때) | **응답이 확정 당시로 고정 → 별도 스냅샷 불필요** |
| 개인 초대 | `private.participant_invites`(약속) · `private.group_invites`(모임방 멤버) — 해시 저장, 1회 수락 | 변경 없음 |
| 공용 초대 | `private.group_join_links`(007) — 해시 저장, 관리자만 발급·회전·폐기 | 원문은 만든 기기에만. 다른 기기에서는 ‘새 링크로 바꾸기’(이전 공용 링크만 무효) |
| 시간 | `timestamptz`(절대 시각) 저장, 화면은 `Asia/Seoul` | 서머타임 없음. 종일 일정·시간 미정 일정은 **모델에 없음** |

권한: 약속 상세(응답·장소)는 그 약속 참여자·주최자만, 모임방 멤버는 목록(제목·상태·날짜)만, 캘린더는 `my_calendar`(본인 것만). 모든 쓰기는 권한 검사 RPC.
