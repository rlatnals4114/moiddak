## C. 확인해서 문제없던 것
- 기본 파란 링크 0, 글 입력칸 16px 미만 0, 가로 넘침 0(앞선 점검), 화면 이모지 0(공유 문구 제외), 홈 하단 버튼·스크롤 그대로.
- 흐름: 링크 참여 → 일정 응답 → 확정 → 참석 여부, 모임방 만들기 → 홈 알림 → 친구 초대, 멤버 링크 → 나가기 → 재가입, 미응답 확정 경고(돌아가기 시 확정 안 됨).
