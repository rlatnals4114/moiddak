# 모이딱 사용자 테스트 기록지

> 실제 친구 4~5명이 쓰는 모습을 **관찰한 그대로** 적는다. 빈칸을 추측으로 채우지 않는다. 측정하지 않은 값은 "미측정"으로 둔다.
> 발표에서 수치를 쓸 때는 이 기록지에 적힌 값만 쓴다.

## 진행 방법 (진행자용)

1. 시연용 모임 두 개를 쓴다: **A(시간 후보 투표)**, **B(30분 시간표)**. 참가자를 반으로 나눠도 되고 둘 다 해 봐도 된다.
2. 참가자에게는 **"카카오톡으로 받은 링크를 눌러서 가능한 시간을 알려 주세요"** 한 문장만 말한다. 화면 설명을 미리 하지 않는다.
3. 링크를 누른 순간부터 "응답을 저장했어요"가 뜰 때까지 시간을 잰다(휴대폰 스톱워치).
4. 도움을 요청하면 도와주되 **무엇을 물었는지** 그대로 적는다.
5. 끝나면 아래 질문을 하고 답을 **들은 말 그대로** 적는다.
6. 주최자 역할도 한 명 정해 "아직 응답 안 한 사람이 누구예요?"라고 묻고, 찾는 데 걸린 시간을 잰다.

## 인터뷰 질문 (끝난 뒤)

1. 어디가 가장 헷갈렸어요? 어떤 문구가 이해가 안 됐어요?
2. 설명 없이 끝까지 할 수 있었어요? 어디서 멈칫했어요?
3. 카카오톡 투표(또는 단톡방에서 시간 묻기)와 비교하면 어땠어요? 더 편했어요, 불편했어요? 왜요?
4. (주최자) 누가 아직 응답 안 했는지 바로 보였어요?
5. 하나만 고친다면 뭘 고치고 싶어요?

# 2.0 추가 과제 (모임방·캘린더·장소)

> 1.x 과제와 같은 규칙: 관찰한 그대로, 측정 안 한 값은 "미측정". 화면 설명을 미리 하지 않는다.
> 진행자가 주는 말은 과제마다 **아래 한 문장만**.

| U2 | "다음 주 약속에 가능한 시간을 알려 주세요." (모임방 약속, 새 링크 없음) | 응답 저장 |
