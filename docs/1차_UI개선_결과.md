## 변경 내용
- **C1 모임방 만들기 → 홈**: 성공하면 홈으로 이동, 위쪽에 ‘‘이름’ 모임방을 만들었어요’ 알림(닫기 가능) + `친구 초대하기`(모임방으로 가며 초대 패널이 열린 채). 홈 ‘내 모임방’에 바로 보임. 실패하면 이동하지 않음. (`screens/Groups.js`, `screens/Home.js`)
  - **발견·수정한 버그**: ‘모임방 만들기’를 빠르게 두 번 누르면 모임방이 **2개** 생겼다(상태 반영 전 두 번째 클릭). 생성 버튼 4곳(모임방, 모임방 약속, 일회성 약속, 장소 직접 올리기)에 즉시 잠금 → 3번 연타해도 1개 확인.
- **C3 장소 화면 간격**: 검색·필터 ↔ 지도 ↔ 후보 목록 사이 24px, 분류 묶음마다 구분선·16px, 카드 안 여백 16px, ‘어디든 좋아요’ 버튼이 카드에 붙지 않게. 지도 크기·마커·검색 그대로. (`styles/app.css`)
- **B5 픽셀 아이콘**: 장소 분류 6종 이모지(📍🍽☕🎳🏞📌) → 같은 격자의 픽셀 아이콘(핀·그릇·컵·티켓·산·깃발, 분류별 진한 색). 미응답 ⏰ → 픽셀 시계, 후보 체크 ✅⬜ → 체크 상자, 시간표 탭 ✏️📊 제거, 응답 완료 🎉 → 픽셀 반짝이, 관리 ⚠️ → ‘주의:’. 카톡에 붙여 넣는 공유 문구의 이모지와 `<select>` 목록은 글자만(아이콘을 넣을 수 없는 곳). (`ui/Pixel.js` KindIcon, 각 화면)
- **B5 빈 화면**: 내 모임방 없음(+ 모임방 만들기), 다가오는 약속 없음, 전체 약속 없음, 장소 후보 없음, 캘린더 일정 없음, 모임방의 진행 중/다가오는/지난 약속 없음 — 픽셀 아이콘 + 설명(+ 다음 행동). (`ui/common.js` EmptyState)
- **C4 기본 스타일 점검**: 글 속 링크(파란 얇은 밑줄) → 브랜드 진파랑·굵은 밑줄. 그 외 기본 링크·체크박스·입력은 앞선 작업에서 정리 완료. 카카오맵 자체 버튼·브라우저 선택 상자는 손대지 않음.
