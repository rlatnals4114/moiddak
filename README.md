# MOIDDAK (모이딱)

An AI-assisted web application for coordinating group schedules and venues.

## Overview

MOIDDAK was independently developed during the PLAN_Be Season 10 Hackathon (November 7–8, 2026).

The project aims to simplify group meeting coordination by bringing scheduling, availability tracking, and venue selection into one shared workflow.

## Key Features

- Create and share group meeting links
- Collect participants' available dates and times
- Track responses and pending participants
- Compare venue options and preferences
- Confirm meeting details and share the final schedule
- Support calendar integration

## Tech Stack

- Frontend: Preact
- Database: Supabase
- Hosting: Cloudflare Workers
- AI-Assisted Development: Claude Code

## Development & Testing

This project was planned, implemented, and tested independently using AI-assisted development tools.

Key activities included:
- Defining user requirements and workflows
- Building interactive scheduling features
- Testing application functionality
- Identifying and resolving usability issues
- Fixing 6 workflow issues and 9 interface design issues during final review

## Project Status

Developed and demonstrated during the November 2026 hackathon.

The original live service is no longer available. This repository preserves the project for documentation and portfolio purposes.
