# 모이딱 캐릭터 에셋 패키지 v1

모이딱의 민트·핑크·블루·옐로우 기본 캐릭터 4종과 교체 가능한 픽셀 파츠의 실제 파일 패키지입니다. 단순한 컨셉 그림을 잘라낸 파일이 아니라, **24×32 픽셀 격자에서 직접 생성한 투명 PNG 및 SVG**입니다.

## 폴더

- `base/`: 완성된 캐릭터 4종. `mint_24x32.png`, `pink_24x32.png`, `blue_24x32.png`, `yellow_24x32.png`와 각각 2×/4×/8× PNG.
- `svg/`: Figma에서 불러올 수 있는 캐릭터별 SVG. 정확한 픽셀 색상과 격자를 유지합니다.
- `parts/hair_back/`, `parts/hair_front/`: 헤어 뒷부분·앞부분. 파일 이름은 `스타일_색상.png`.
- `parts/skin/`, `parts/face/`, `parts/top/`, `parts/bottom/`, `parts/accessory/`: 바꿔 끼울 수 있는 투명 파츠. 모두 동일한 24×32 캔버스.
- `status/`: 미응답 실루엣 및 상태 아이콘.
- `preview/characters_overview.png`: 4종 디자인 확인용 이미지.
- `preview/customizer_demo.html`: 파츠를 바꿔 보는 오프라인 데모. `python3 -m http.server 8080` 실행 후 브라우저에서 `http://localhost:8080/preview/customizer_demo.html`로 열기 권장.

## Figma

1. `svg/mint.svg` 등 4종을 드래그해 가져오면 기본형을 사용할 수 있습니다.
2. 각 PNG 파츠는 **같은 24×32 캔버스**에 정렬해 겹치세요. 레이어 순서는 `hair_back → bottom → skin → top → face → hair_front → accessory`입니다.
3. 화면에서는 2배/4배처럼 **정수 배율**로 확대하고 보간(흐림) 없이 표시합니다.
4. 캐릭터 꾸미기 UI는 기존 화면 디자인과 별도로 Figma에서 제작할 수 있으며, 앱 구현 시 아래 파츠를 조합하면 됩니다.

## Claude Code 반영

1. `base/*_4x.png` 등을 프로젝트 `public/characters/` 안에 복사합니다.
2. 현재 구현의 `characters/index.js` `IMAGE_OVERRIDES` 실제 매핑 구조를 확인한 다음, 민트·핑크·블루·옐로우 경로를 매핑합니다. **기존 구조를 확인하지 않고 코드를 덮어쓰지 마세요.**
3. 완성 캐릭터 PNG 교체와 별개로 파츠 꾸미기를 구현할 경우, 사용자의 파츠 선택값(헤어/피부/상의/하의/표정/액세서리)을 저장하고 클라이언트에서 동일 격자의 PNG 레이어를 합성합니다.
4. 모임방의 응답 상태는 캐릭터 외형과 별도로 표시합니다. 미응답/응답 완료/가능한 시간 없음은 단순 캐릭터 색만으로 구별하지 않고 텍스트·아이콘을 함께 사용합니다.
5. Supabase 변경이 필요하면 추가 마이그레이션으로 수행하고, 기존 테이블·행·권한·초대 기능을 보존합니다.

## 참고

- 본 패키지는 **첫 에셋 버전**입니다. 참고 시안의 섬세한 일러스트를 이미지 추출한 것이 아니며, 작은 원본 격자에 맞춘 일관된 캐릭터 시스템입니다.
- Piskel을 사용하거나 직접 도트를 찍을 필요 없이, 이 파일들을 Figma에 가져오거나 Claude Code 프로젝트에 전달할 수 있습니다.
- `24×32` 원본과 `SVG`는 픽셀 기준 구조를 갖지만 Figma 전용 `.fig` 프로젝트 파일은 아닙니다.
